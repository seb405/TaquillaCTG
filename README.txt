TaquillaCTGVenta de boletas por localidad para eventos culturales en Cartagena.Proyecto integrador 3 de Programación II – POO y JavaInstitución Universitaria Colegio Mayor de Bolívar · Ingeniería Informática · Sede CartagenaDocente: Ing. UML, documento corto, casos de prueba y storybook└── src/    └── taquilla/        ├── modelo/        # Clases del dominio        │   ├── Evento.java        │   ├── Localidad.java        │   ├── Comprador.java        │   └── Boleta.java        ├── servicio/      # Taquilla (arreglos de eventos y boletas) – Entrega 2        └── app/           # Main con el menú – Entrega 2            └── PruebaModelo.java   # Prueba de las clases del modelo (Entrega 1)```Clases del modeloClase	Atributos principales	Métodos principales`Evento`	codigo, nombre, fecha, lugar, localidades[]	agregarLocalidad(), buscarLocalidad(), toString()`Localidad`	nombre, precio, aforo, vendidas	hayCupo(), vender(), liberar(), ocupacion()`Comprador`	documento, nombre, edad	constructor con validación, getters`Boleta`	numero (consecutivo), evento, localidad, comprador, valorPagado	constructor, toString()`Taquilla` (servicio)	eventos[], boletas[]	venderBoleta(), aplicarDescuento(), reporteEvento()Todos los atributos son privados. Los getters y setters no aparecen en el UML por ser sobreentendidos; los setters validan los datos y `vendidas` no tiene setter para que el aforo solo cambie con `vender()` y `liberar()`.RequisitosJDK 17 o superiorIntelliJ IDEA Community, Eclipse o NetBeans (opcional)Cómo compilar y ejecutarDesde la carpeta raíz del proyecto:```bash# Compilarjavac -d out src/taquilla/modelo/*.java src/taquilla/app/*.java# Ejecutar la prueba del modelo (Entrega 1)java -cp out taquilla.app.PruebaModelo```En IntelliJ IDEA: abrir la carpeta `TaquillaCTG`, marcar `src` como Sources Root y ejecutar `PruebaModelo`.AlcanceSe usan arreglos de tamaño fijo con contador, `Scanner`, estructuras de control (`if`, `switch`, `while`, `do-while`, `for`), constructores, `this`, `private`/`public`, getters y setters, y paquetes.
